---
title: My project stopped sending
description: What to do when a mailbox or LinkedIn account disconnects, or a project pauses.
---

If outreach stops, the project shows why. Work through the case that matches.

## Sending is paused on every channel

A password change or revoked access can disconnect a mailbox, and LinkedIn sessions expire from time to time. Rose pauses every project sending from that account, on every channel, so no candidate gets half a sequence.

Click **Reconnect mailbox** or **Reconnect LinkedIn**. The project picks up where it left off on its own. Already reconnected? You can **Resume now**.

Only the project owner can reconnect, because a project sends from its owner's accounts. See [Mailboxes](/integrations/mailboxes) and [LinkedIn](/integrations/linkedin).

## Only LinkedIn steps are going out

No inbox is connected for the email steps. They wait until the project owner connects one.

## The project says Paused

Someone paused it, or Rose did. Click **Resume** on the project page. See [Project Statuses](/projects/project-statuses).

## Still stuck?

Email [support@gethiros.com](mailto:support@gethiros.com) with the project name.
