Already have a list of people? Import it into a project from a CSV. Hiros refreshes each profile so you have relevant data to work with.

## Importing a CSV

You can start an import in two ways:

- **On the project page** — click **Import CSV** and choose your file.
- **In a chat with Rose** — ask her, for example *“Import candidates from a CSV into this project”*, and she opens an upload card.

## What the file needs

- **A column of LinkedIn profile URLs.** Hiros finds the column itself.
- **Up to 1,000 rows.** For a longer list, or if the file is too large, split it into smaller files.

## What it costs

Each new person uses credits, and the cost is shown before you import. People already in the project are not charged again. See [Credits](/billing-and-subscription/credits).

## After the import

A summary shows how many candidates were added, how many were already in the project, and how many rows were skipped. Rows without a valid LinkedIn URL are not added, and the summary also shows any rows whose profile couldn't be retrieved. Contact details from your file are labelled **Imported - CSV**.

Large files may take a while. Candidates appear in the project when the import finishes.

<Callout kind="warning">
  On a live project, imported candidates are added to the project only. They are not enrolled in the live email sequence.
</Callout>
