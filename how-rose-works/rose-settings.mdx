**Settings › Rose** holds your own defaults for how Rose handles replies. Open it from **More → Settings** in the left sidebar.

## Replies on new projects

Every new project starts with these settings. Existing projects keep their own, so changing them here won't affect a project that's already set up.

- **Reply mode** — **Rose replies automatically**, **Rose drafts, you approve**, or **You reply yourself**.
- **Goal** — what Rose works toward after a reply. See [Reply Objectives](/how-rose-works/reply-objectives).

If you haven't changed anything, new projects start with **Rose drafts, you approve** and **Ask for availability**.

To change one project, use its **Reply handling** tab. See [Managing a Project](/projects/managing-a-project).

## Your links

- **Your scheduling link** — used when a project's objective is **Send scheduling link**. It belongs to the project owner, so a teammate's project uses their link.
- **Application page link** — used when the objective is **Application page**. It must start with `https://`.

## When a goal is met

Choose how you hear about it:

- **Email me**
- **Post in Slack**, which needs Slack connected. See [Notifications](/integrations/notifications).

These settings apply to projects you own, and you hear about each candidate once.

The **How replies will work** preview shows the result of your choices before you save. Click **Discard** to drop unsaved changes.
